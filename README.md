<h3>The FiremeX QA architecture consists of CCTV cameras and an NVR feeding video streams to a GPU-based AI inference server, which processes fire/smoke detection and sends results through the backend to the QA database, dashboard, and sandbox notification/mock fire-panel services for end-to-end testing.</h3>
